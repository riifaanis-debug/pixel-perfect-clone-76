# دليل حسابات سناب شات — تطبيق جوال (RTL)

## البيانات
- تحويل ملف Excel المرفق أثناء البناء إلى ملف بيانات مضمّن في التطبيق (يعمل فورًا دون رفع).
- الأقسام الثمانية بأعدادها الفعلية (بعد استبعاد الصفوف الفارغة): الأصدقاء ~2046، طلبات مرسلة ~680، المعلّقة ~338، المحذوفون ~417، المحظورون ~241، الاقتراحات المخفية ~3، المتجاهلون (يُتحقق)، إشعارات الاشتراكات ~39 (بدون اسم ظاهر — يُعرض "بدون اسم").
- استخدام الرابط من الملف، وإنشاؤه من اسم المستخدم إن غاب.
- خيار "استيراد ملف جديد" محليًا داخل المتصفح (SheetJS) يستبدل البيانات ويُحفظ على الجهاز؛ لا إرسال لأي خادم.

## الصفحات
- `/` الرئيسية: العنوان، إجمالي الحسابات، 8 بطاقات أقسام بأيقونة وعدد، بطاقة "جميع الحسابات"، بطاقة "المفضلة".
- `/section/$id` قائمة القسم: شريط علوي ثابت (اسم القسم + رجوع + العدد)، بحث فوري ثابت، ترتيب (الأصلي / الاسم / اسم المستخدم)، قائمة افتراضية مستمرة التمرير حتى آخر سجل، حفظ موضع التمرير.
- `/all` جميع الحسابات مع شارة القسم لكل سجل.
- `/favorites` المفضلة مع بحث.

## بطاقة الحساب
الاسم الظاهر (مع الرموز)، اسم المستخدم قابل للنسخ، زر أصفر "فتح الحساب"، نسخ الرابط، نجمة مفضلة (localStorage)، إشعار نسخ.

## التصميم
iOS نظيف، خلفية بيضاء، أصفر سناب للأزرار، خط IBM Plex Sans Arabic، حواف مستديرة، دعم المنطقة الآمنة، وضع داكن تلقائي، منع التمرير الأفقي.

## تقني
- سكربت Python لمرة واحدة يولّد `src/data/snapchat.json`.
- `@tanstack/react-virtual` للقائمة، `xlsx` للاستيراد المحلي.
- `html dir="rtl" lang="ar"`، head() لكل صفحة، ورابط noindex للخصوصية.
- التحقق: مطابقة الأعداد مع الأوراق، واختبار مرئي بعرض جوال.
